## Обработка ошибок (исключения)

### Основные принципы

Обработка исключений в Python позволяет программе корректно реагировать на ошибки во время выполнения.

**Конструкция try-except-else-finally:**
```python
try:
    # Код, который может вызвать исключение
    pass
except SomeException as e:
    # Обработка конкретного исключения
    print(f"Ошибка: {e}")
except Exception as e:
    # Общая обработка всех остальных исключений
    print(f"Неожиданная ошибка: {e}")
else:
    # Выполняется, если исключение не было выброшено
    print("Всё прошло успешно!")
finally:
    # Выполняется всегда, независимо от наличия исключения
    print("Завершение работы")
```

**Создание пользовательского класса-исключения:**
```python
class CustomError(Exception):
    def __init__(self, message):
        self.message = message
        super().__init__(self.message)
```

**Выброс исключения:**
```python
raise CustomError("Описание ошибки")
```

## Работа с файлами. Контекстные менеджеры

### Контекстный менеджер (with statement)

Контекстный менеджер автоматически управляет ресурсами, гарантируя закрытие файла даже при возникновении ошибки.

```python
# Безопасная работа с файлом
with open('file.txt', 'r') as f:
    content = f.read()
# Файл автоматически закрывается
```

### Создание собственного контекстного менеджера

```python
class MyContextManager:
    def __enter__(self):
        print("Вход в контекст")
        return self
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Выход из контекста")
        return False  # True - подавляет исключение, False - пробрасывает

# Использование
with MyContextManager() as mcm:
    print("Работаем в контексте")
```

## Функциональное программирование

### Основные концепции:

**1. Чистые функции** - функции, которые:
- Не изменяют внешнее состояние
- Для одних и тех же аргументов возвращают одно и то же значение
- Не имеют побочных эффектов

**2. Неизменяемость данных** - создание новых структур вместо изменения существующих

**3. Функции высшего порядка** - функции, принимающие или возвращающие другие функции

### map() - применение функции к каждому элементу

```python
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x**2, numbers))
# [1, 4, 9, 16, 25]
```

### filter() - фильтрация элементов

```python
numbers = [1, 2, 3, 4, 5, 6]
even = list(filter(lambda x: x % 2 == 0, numbers))
# [2, 4, 6]
```

### zip() - объединение последовательностей

```python
names = ['Alice', 'Bob', 'Charlie']
ages = [25, 30, 35]
pairs = list(zip(names, ages))
# [('Alice', 25), ('Bob', 30), ('Charlie', 35)]
```

```python
# В функциях высшего порядка
```

### Списочные выражения (List comprehensions)

Компактный способ создания списков:

## Декораторы

### Концепция

Декоратор - это функция, которая принимает функцию как аргумент и возвращает новую функцию с расширенной функциональностью.

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("Что-то до функции")
        result = func(*args, **kwargs)
        print("Что-то после функции")
        return result
    return wrapper

@my_decorator
def say_hello(name):
    print(f"Hello, {name}!")

say_hello("Alice")
```

### Декораторы с параметрами

```python
def repeat(times):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(times):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(times=3)
def greet():
    print("Hi!")
```

```python
class MyClass:

    def my_attr(self):
        return self._attr
    
    @staticmethod
    def static_method():
        pass
    
    @classmethod
    def class_method(cls):
        pass
```

### Структура теста

```python
class TestCalculator(unittest.TestCase):

        # Подготовка перед каждым тестом

    def tearDown(self):
        # Очистка после каждого теста
        pass
    
    def test_something(self):
        # Arrange - подготовка данных

        # Act - выполнение операции

        # Assert - проверка результата
```

## Сетевое взаимодействие

### Протоколы IP, TCP, UDP

#### IP (Internet Protocol)

- **Уровень:** Сетевой (3-й уровень OSI)
- **Функция:** Маршрутизация пакетов между компьютерами
- **Адресация:** IP-адреса (IPv4: 192.168.1.1, IPv6)
- **Ненадежный** - не гарантирует доставку пакетов
- **Без установления соединения** - не требует предварительной договоренности

#### TCP (Transmission Control Protocol)

- **Уровень:** Транспортный (4-й уровень OSI)
- **Надежность:** Гарантирует доставку данных в правильном порядке
- **Соединение:** Требует установления соединения (3-way handshake)
- **Скорость:** Медленнее, чем UDP из-за проверок
- **Использование:** HTTP, HTTPS, FTP, SSH, Telnet
- **Поток данных:** Непрерывный поток байтов

#### UDP (User Datagram Protocol)

- **Уровень:** Транспортный (4-й уровень OSI)
- **Ненадежность:** Не гарантирует доставку
- **Соединение:** Без установления соединения (connectionless)
- **Скорость:** Быстрее TCP
- **Использование:** DNS, Video streaming, Online games, VoIP
- **Пакеты:** Отдельные датаграммы
- **Задержка:** Минимальная, допускаются потери

#### Основные различия

| Характеристика | TCP | UDP |
|---|---|---|
| **Надежность** | Надежный | Ненадежный |
| **Установление соединения** | Да | Нет |
| **Скорость** | Медленнее | Быстрее |
| **Порядок доставки** | Гарантирован | Не гарантирован |
| **Потери данных** | Нет | Возможны |
| **Использование** | Web, Email | Видео, игры |

## Дискретное преобразование Фурье (DFT)

### Концепция

Преобразование Фурье разлагает сигнал на сумму синусоидальных компонент с разными частотами.

### Формула DFT

```
X[k] = Σ(n=0 to N-1) x[n] * e^(-i*2π*k*n/N)

где:
- X[k] - комплексное число (результат для частоты k)
- x[n] - входной сигнал
- N - количество отсчетов
- i - мнимая единица
- e - число Эйлера
```

### Вычисление вручную для (a, b)

Для набора из двух элементов (a, b), N=2:

```
X[0] = a*e^(-i*2π*0*0/2) + b*e^(-i*2π*0*1/2)
     = a*1 + b*1
     = a + b

X[1] = a*e^(-i*2π*1*0/2) + b*e^(-i*2π*1*1/2)
     = a*1 + b*e^(-iπ)
     = a + b*(-1)
     = a - b

Результат: [a+b, a-b]
```

### Примеры вычисления:

**Для (0, 1):**
- X[0] = 0 + 1 = 1
- X[1] = 0 - 1 = -1
- Результат: [1, -1]

**Для (1, 0):**
- X[0] = 1 + 0 = 1
- X[1] = 1 - 0 = 1
- Результат: [1, 1]

**Для (2, 0):**
- X[0] = 2 + 0 = 2
- X[1] = 2 - 0 = 2
- Результат: [2, 2]

**Для (1, 1):**
- X[0] = 1 + 1 = 2
- X[1] = 1 - 1 = 0
- Результат: [2, 0]

**Для (-1, 0):**
- X[0] = -1 + 0 = -1
- X[1] = -1 - 0 = -1
- Результат: [-1, -1]

**Для (0, -1):**
- X[0] = 0 + (-1) = -1
- X[1] = 0 - (-1) = 1
- Результат: [-1, 1]

### Быстрое преобразование Фурье (FFT)

```python
import numpy as np

# FFT для быстрого вычисления
signal = np.array([0, 1])
fft_result = np.fft.fft(signal)
print(fft_result)  # [1.+0.j -1.+0.j]
```

## Работа с изображениями

### Способы кодирования цвета пикселя

#### RGB (Red, Green, Blue)

Каждый пиксель кодируется тремя числами (0-255):
- **R** (красный): 0-255
- **G** (зеленый): 0-255
- **B** (синий): 0-255

```python
# RGB пиксель
pixel = (255, 0, 0)  # Красный цвет
pixel = (0, 255, 0)  # Зеленый
pixel = (0, 0, 255)  # Синий
pixel = (255, 255, 255)  # Белый
pixel = (0, 0, 0)    # Черный
```

#### RGBA (RGB + Alpha)

Добавляется канал прозрачности (Alpha):
- **A** (альфа): 0-255, где 0 - полностью прозрачный, 255 - полностью непрозрачный

```python
pixel = (255, 0, 0, 128)  # Красный с полупрозрачностью
```

#### HSV (Hue, Saturation, Value)

- **H** (оттенок): 0-360° - положение на цветовом круге
- **S** (насыщенность): 0-100% - интенсивность цвета
- **V** (значение/яркость): 0-100% - яркость

#### CMYK (Cyan, Magenta, Yellow, Key/Black)

Используется в печати:
- Каждый компонент: 0-100%

### Кодирование цвета в компьютере

```python
from PIL import Image
import numpy as np

# Создание изображения 2x2 в RGB
img_array = np.array([
    [(255, 0, 0), (0, 255, 0)],      # Красный, Зеленый
    [(0, 0, 255), (255, 255, 255)]   # Синий, Белый
], dtype=np.uint8)

img = Image.fromarray(img_array, 'RGB')
img.save('image.png')
```
